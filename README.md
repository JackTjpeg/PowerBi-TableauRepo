# PowerBi-TableauRepo
PowerBi/Tableau examples from my course with DeepTalent

Project Overview

As part of a Data Technician Bootcamp, I developed an interactive Tableau dashboard using the Gapminder Health dataset to explore global health trends and compare key health indicators across countries and continents.

The project focused on transforming raw data into meaningful visual insights through interactive dashboards, dynamic filtering, and data visualisation best practices.

Objectives
Analyse global health metrics across continents and countries.
Identify trends in life expectancy, population demographics, and health indicators.
Create an interactive dashboard to support data-driven decision making.
Dashboard Features

The dashboard includes multiple visualisations designed to answer key analytical questions:

Visualisations Created
Bar Chart: Average Life Expectancy by Continent
Line Chart: Life Expectancy Trends Over Time for Top Performing Countries
Pie Chart: Population Distribution by Gender
Scatter Plot: Relationship Between Life Expectancy and BMI
Additional Custom Visualisation to explore further health trends
Interactive Geographic Map for country-level analysis

Key Findings
Countries such as Iceland, Germany, and Denmark showed high cholesterol levels while maintaining strong life expectancy outcomes.
Health outcomes are influenced by multiple factors beyond individual health metrics, highlighting the importance of healthcare quality and accessibility.
Significant variations in health indicators exist across different continents and countries.
